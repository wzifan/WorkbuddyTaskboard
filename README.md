# WorkBuddy待办工作台

#### 理念与特色

- 待办分为工作、自习、生活三类
- 按分组排的待办列表用于日常待办记录
- 所有待办可设置 固定/最早/最晚 开始/结束 时间属性
- 可将近期的或可预测性好的待办参与排期，或临时排期待办以估算任务完成时间
- 每条待办的排期连续且不可拆分，工作与非工作时间各自独立排期
- 时间以半天为单位，每条待办都有已完成时间和总预估完成时间2个属性
- 排期的待办在 已完成时间 = 总预估时间时 为已完成状态，在 已完成时间 < 总预估时间 时为未完成状态
- 对于当前排期的待办，已完成时间随时间流逝自动增加，完成时间等于预估时间时待办自动被设为已完成状态，待办此时实际未完成时可增加总预估时间，或在属性设置里减少已完成时间（固定开始且参与排期的待办不能设置已完成时间）
- 日历和待办列表中的待办都可长按拖动

#### 具体功能

1. **随手记录：**新增普通待办默认不排期，无须填写用时和日期。
2. **按需排期：**可选择参与/不参与排期。
3. **日历拖动：**日历中的待办色块可整体移动，待办列表同步顺序和时间。
4. **列表联动：**“按排期”中上下移待办，日历同步调整。
5. **双向定位：**点日历中的待办色块跳到列表中对应的待办，点列表中的待办跳到日历中对应的待办色块。
6. **日历简称：**待办内容可设日历中显示的简称。
7. **固定时间：**可固定开始或结束，固定排期不可拖动或上下移。
8. **时间要求：**开始、结束均支持“不早于”“不晚于”，排不下时说明原因。
9. **空档休息：**待办因固定时间要求，可能会产生「空」待办，「空」待办可转为休息待办。
10. **自动完成：**参考[**理念与特色**](####理念与特色)部分
11. **上班休息日：**点击日期数字切换，也可恢复官方日历。
12. **归档恢复：**完成后归档留存，需要时恢复。
13. **手机使用：**已针对手机端做了深度优化。
14. **云端同步：**自动同步到WorkBuddy资料库云端，支持多端同时访问，**这是本待办工作台开发耗时最长的地方！已经过深度优化改进。**
15. **更多细节等您发现！**

#### 使用方式

###### 1. 下载本项目至本地

```shell
git clone https://github.com/wzifan/WorkbuddyTaskboard.git
```

###### 2. 使用将本地文件同步至Workbuddy资料库，使其成为可云端同步、多端访问的待办工作台
工作目录选择 `WorkbuddyTaskboard/待办工作台_公开_云端同步/{版本号}` ，专家选择 `工作台搭建师`，提示词在 `WorkbuddyTaskboard/待办工作台_公开_云端同步/{版本号}/加载到云端的提示词.txt` 中。
