# WorkBuddy待办工作台

#### 介绍与理念

待办工作台是一款清单与日历联动的网页应用，适合日常需要处理多项工作、学习和生活事项的人。项目里的几项工作、正在学的课程、约好的活动，既有各自的内容，也有不同的时间要求。清单保留事情本身，日历呈现时间安排，已完成的用时也会留在待办中。

零散想法、暂时没定时间的事，可以先留在清单里；近期要做的，再按预估用时安排。有明确约定的事项可以设置日期要求，远期事项也能先记下，等临近了再参与排期。清单和日历之间的调整会相互对应，排期中的用时随时间累计，预估不够时还能接着增加，保留已经完成的部分。

它既可以用来推进项目、安排学习，也可以记录日常琐事和出行约定。手机和电脑都能通过浏览器使用，云端版同步清单、安排与进度，换个设备也能接着处理。打开页面后，可以直接使用预置示例体验各项操作，也可以从自己的第一条待办开始。

#### 具体功能

1. **分类与分组**：按工作、自习、生活整理待办，同类事项可继续分组；长按待办可以调整分组内的顺序。
2. **随手记录**：新增待办默认留在清单中，无须立即填写用时或安排日期。
3. **按需排期**：为需要安排的待办设置预估用时并开启排期，日历呈现对应时段，工作与非工作时间分别安排。
4. **日历拖动与清单联动**：拖动色块即可调整安排，跨多个时段、占用 1.5 半天的异形色块也能整体移动；拖动时，待办列表同步预览顺序和时间，放下后一起更新。
5. **列表调整与日历联动**：在排期列表中上下移动待办，改变先后顺序，日历里的对应色块随之调整。
6. **双向定位**：点击日历色块，列表定位到对应待办；点击待办的时间信息，也能回到日历查看。
7. **日历简称**：待办保留完整名称，日历可单独设置简称，方便在小格子中辨认。
8. **固定时间**：待办可以固定开始或结束日期及时段，保留已经确定的安排。
9. **时间要求与冲突提示**：支持“不早于”“不晚于”等要求，时间矛盾或安排不下时会说明原因。
10. **远期事项**：先记录较远日期的约定或截止要求，临近时再参与排期，避免日历被远期安排铺满。
11. **空档与休息**：有时间要求的安排之间会呈现必要空档，也可以把空档转为休息待办。
12. **自动完成与追加预估**：随着排期时间流逝，累计已完成用时，并在安排结束后标记为已完成。如果事情实际还没做完，增加总预估用时即可恢复为未完成，已经累计的用时继续保留。
13. **调整上班与休息日**：点击日历的日期数字，即可切换当天的上班、休息状态，相关安排随之调整。
14. **归档与恢复**：完成的待办可以收进归档，记录仍然保留，需要时可以恢复到清单。
15. **手机使用**：手机上也能查看日历、整理待办、调整预估和设置时间要求。
16. **云端同步**：在不同设备间接续查看和编辑；同步时保护正在进行的编辑、拖动等操作，保存后核对结果，异常时给出提示。

#### 使用方式

###### 1. 下载本项目至本地

```shell
git clone https://github.com/wzifan/WorkbuddyTaskboard.git
```

###### 2. 使用将本地文件同步至Workbuddy资料库，使其成为可云端同步、多端访问的待办工作台
工作目录选择 `WorkbuddyTaskboard/待办工作台_公开_云端同步/{版本号}` ，专家选择 `工作台搭建师`，提示词在 `WorkbuddyTaskboard/待办工作台_公开_云端同步/{版本号}/加载到云端的提示词.txt` 中。
